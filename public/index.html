What This Means

Emergency Fund and Debt Load use simplified proxies — average recent spend stands in for "essential" expenses, and Debt Load measures account balances rather than actual monthly payments. Set which accounts count as liquid savings or investments under Emergency Fund Accounts and Investment Accounts below. These are a starting point for your own judgment, not financial advice.

Actual Budget Configuration

The web address of your Actual Budget instance.

Your master login password.

How to find this: Open Actual Budget in your browser -> Go to Settings -> Click Show advanced settings -> Copy the long Sync ID string.

Cron format: 0 6,12 * * * syncs at 6:00 AM and 12:00 PM (Noon) daily.

Email Notifications

Send an HTML summary of new transactions.

If set, the email report includes a "View Full Report" button linking here.

If using Gmail, use a 16-digit App Password.

Separate multiple addresses with commas — e.g. alice@example.com, bob@example.com.

Connection issue alerts are always included regardless of these settings.

Webhook Notifications

Post a sync summary to a Discord or Slack channel instead of (or alongside) email.

Discord: channel > Edit Channel > Integrations > Webhooks. Slack: create an Incoming Webhook app.

Access & Sharing

Give someone else (e.g. a spouse) a read-only login that can view the dashboard and Data Explorer but can't change settings or trigger syncs.

Read-only access is currently disabled.

Emergency Fund Accounts

Actual doesn't distinguish checking/savings/investment accounts — it only knows names and balances. Check which accounts should count as liquid emergency savings for the Financial Health Check widget.

Configure Actual Budget above and save to see your accounts here.

Investment Accounts

Same limitation as above — check which accounts (brokerage, 401k, IRA, etc.) should count as investments for the Net Worth Breakdown on the Financial Health Check widget. An account can't be both liquid and investment.

Configure Actual Budget above and save to see your accounts here.

Backup & Restore

Download your settings to restore them later, or after moving to a new host. The backup file contains your Actual Budget and SMTP credentials in plain text — store it somewhere safe.
