Account Classification

Actual doesn't distinguish checking/savings/investment/liability accounts — it only knows names and balances. Classify each account once here; it drives the Financial Health Check widget, Net Worth Breakdown, Financial Insights projections, and the Liability Accounts section of sync emails. Usually a one-time setup — revisit only when you add or close an account.

Configure Actual Budget above and save to see your accounts here.

Social Security (Optional)

Your SSA statement (ssa.gov/myaccount) gives three claiming ages, each with its own monthly benefit — enter as many as you have and pick which one to actually plan around below. Leave everything blank to ignore Social Security entirely (the FIRE Number then works exactly as before). All optional and usually a one-time setup.

Before the age you pick, the FIRE Number still assumes you're covering every expense from savings alone (Social Security hasn't started yet) — it only gets smaller once benefits would actually begin.

Email Notifications

Send an HTML summary of new transactions.

If set, the email report includes a "View Full Report" button linking here.

If using Gmail, use a 16-digit App Password.

Separate multiple addresses with commas — e.g. alice@example.com, bob@example.com.

Connection issue alerts are always included regardless of these settings.

Webhook Notifications

Post a sync summary to a Discord or Slack channel instead of (or alongside) email.

Discord: channel > Edit Channel > Integrations > Webhooks. Slack: create an Incoming Webhook app.

Feedback

Needs "Issues: Read and write" permission on the repo above.

Access & Sharing

Give someone else (e.g. a spouse) a read-only login that can view the dashboard and Data Explorer but can't change settings or trigger syncs.

Read-only access is currently disabled.

Backup & Restore

Download your settings to restore them later, or after moving to a new host. The backup file contains your Actual Budget and SMTP credentials in plain text — store it somewhere safe.
